# Booknote-Svelte 📚

독서 기록과 분석을 위한 모던 웹 애플리케이션입니다. Svelte와 TypeScript를 사용하여 개발되었습니다.

## 주요 기능 ✨

### 1. 독서 기록 관리
- 📖 책 정보 등록 및 관리
  - 제목, 저자, 출판사, ISBN 등 기본 정보
  - 읽은 날짜, 완독 여부 기록
  - 별점 및 리뷰 작성
- 📝 독서 노트 작성
  - 인상 깊은 구절 하이라이트
  - 개인적인 생각과 메모 기록
  - 태그를 통한 카테고리 분류

### 2. 독서 통계 및 분석
- 📊 독서 현황 대시보드
  - 월간/연간 독서량 추적
  - 장르별 독서 비율 분석
  - 독서 시간 추적
- 📈 독서 트렌드 분석
  - 기간별 독서 패턴 분석
  - 선호 장르 변화 추적
  - 독서 습관 개선 포인트 제시

### 3. 시각화 기능
- 🎯 키워드 클라우드
  - 자주 등장하는 키워드 시각화
  - 독서 취향 분석
- 📊 차트 및 그래프
  - 독서량 추이 그래프
  - 장르 분포 파이 차트
  - 월별 독서 현황 바 차트

### 4. 커뮤니티 기능
- 👥 독서 모임 관리
  - 독서 모임 생성 및 참여
  - 독서 토론 스레드
- 💬 독서 토론
  - 책별 토론방
  - 인상 깊은 구절 공유
  - 독서 경험 나누기

### 5. 개인화 기능
- 🎨 맞춤형 대시보드
  - 사용자 정의 위젯 배치
  - 중요 지표 커스터마이징
- 📱 반응형 디자인
  - 모바일/태블릿/데스크톱 최적화
  - 다크 모드 지원

### 6. 데이터 관리
- 💾 데이터 백업 및 복원
  - 자동 백업 기능
  - 데이터 내보내기/가져오기
- 🔄 동기화
  - 여러 기기 간 데이터 동기화
  - 실시간 업데이트

## 기술 스택 🛠

- **프론트엔드**
  - Svelte 5.0
  - TypeScript
  - Tailwind CSS
  - Chart.js (데이터 시각화)

- **개발 도구**
  - Vite
  - ESLint
  - Prettier
  - TypeScript

## 시작하기 🚀

### 필수 조건

- Node.js (최신 LTS 버전)
- npm 또는 yarn

### 설치

```bash
# 저장소 클론
git clone https://github.com/yourusername/Booknote-Svelte.git

# 프로젝트 디렉토리로 이동
cd Booknote-Svelte

# 의존성 설치
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

개발 서버는 기본적으로 http://localhost:5188 에서 실행됩니다.

### 빌드

```bash
npm run build
```

```
src/

```

## 개발 가이드 📝

### 코드 스타일

- ESLint와 Prettier를 사용하여 코드 스타일을 관리합니다.
- TypeScript를 사용하여 타입 안정성을 보장합니다.

### 스크립트

- `npm run dev`: 개발 서버 실행
- `npm run build`: 프로덕션 빌드
- `npm run check`: TypeScript 타입 체크
- `npm run format`: 코드 포맷팅
- `npm run lint`: 린트 검사
